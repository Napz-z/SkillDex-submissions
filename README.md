# SkillDex — Public Submissions & Corrections

**Find the skill your agent is missing.**

This repository is the public intake channel for **[SkillDex](https://skilldex.io)**, a curated agent skills marketplace for Claude Code, Codex, Cursor, and Gemini. Every listing on SkillDex is checked against its upstream source and records the original repository, license, reviewed commit, and review date.

- **Browse the directory:** [skilldex.io](https://skilldex.io)
- **Submit a skill or correction:** [Open the submission form](https://github.com/Napz-z/SkillDex-submissions/issues/new?template=skill.yml)

> Website source code is maintained separately. All submissions and corrections in this repository are public—please do not include secrets or private personal data.

## What We Check Before Listing

1. **Verifiable upstream source**: A public repository or `SKILL.md` link we can inspect directly.
2. **Clear license**: An identifiable upstream license linked on the detail page.
3. **Clear scope**: We distinguish standalone skills from collections, CLI tools, and MCP servers.
4. **Honest provenance**: Each published entry records the reviewed commit and review date without invented ratings or unverified runtime claims.

## How to Contribute

1. Check whether the skill is already listed on [skilldex.io](https://skilldex.io/skills).
2. Open the **[Skill / Correction Form](https://github.com/Napz-z/SkillDex-submissions/issues/new?template=skill.yml)**.
3. Include the upstream repository or `SKILL.md` URL, category, short summary, and license link.
